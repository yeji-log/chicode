교사와 학생이 웹 브라우저에서 수업자료를 확인하고 Python을 실습하는 교육 플랫폼입니다.
학생은 **설치도 회원가입도 없이** 브라우저만으로 참여합니다.

## 기능

| | |
| --- | --- |
| **수업자료** | 교사가 올린 PDF·이미지·문서를 웹에서 바로 열어보고 내려받습니다 |
| **Python 실습** | 코드를 쓰고 실행하면 결과가 옆 창에 나옵니다. 오류는 몇 번째 줄이 잘못됐는지 짚어줍니다 |
| **교사 페이지** | Google 로그인. 허용된 계정만 자료를 올리고 지울 수 있습니다 |

## Python이 도는 곳

Python은 **학생 브라우저 안에서** 실행됩니다. Pyodide(WebAssembly로 컴파일된 CPython)를
쓰기 때문에 코드가 서버로 나가지 않고, 실행 횟수가 늘어도 서버 비용이 생기지 않습니다.

실행은 Web Worker에서 처리해 무한 루프에 빠져도 화면이 멈추지 않고 **중지** 버튼으로 끊을 수 있습니다.

## 권한

Google 로그인에 성공했다고 교사가 되는 것이 아닙니다. 허용 목록에 있는 계정만 교사로 인정하며,
그 검사는 브라우저가 아니라 **Firebase 보안 규칙이 서버에서** 수행합니다. 프론트엔드 코드를
고쳐 화면을 열어도 자료를 쓰거나 지울 수 없습니다.
